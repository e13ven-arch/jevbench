# JevBench v1.3.1 — round-4 additions

v1.3.1 adds 18 independently reviewed rows. Every row ran all 534 decisions in
the frozen v1.2 task set and is scored by the unchanged v1.3.0 formula. No
earlier measurement, task, answer, scoring weight, or ranking rule changed.

The release includes LocalJev Qwen3.5 4B, MetaSK Jev 4B, Jobe Qwen3.5 4B,
three NInfer configurations, Hopper, Mirror, JevOne, SwanOne, Jev Qwen3.5 9B
Base NVFP4, SimpleJev Qwen3.5 0.8B, JoshuaSP/open-jev, and five neutral
raw-logit controls (Qwen3 0.6B, 1.7B and 8B, Qwen3-4B-Instruct-2507, and
Phi-4-mini).

Each row has a standard aggregate artifact and a paired per-task artifact in
[`results/v1.2/additions/`](../results/v1.2/additions/). The aggregate records
the pinned implementation and model revisions, licence, endpoint condition,
non-zero hosted-reference cost basis, and training-data-overlap audit. The
paired evidence records public task outcomes and held-out aggregate counts
without revealing held-out benchmark material.

Reflex 0.8B and typed-engine remain pending independent review and are not in
this release. Private djev experimental work is also excluded.
